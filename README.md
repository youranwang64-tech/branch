# branch by parallax

Public homepage and real event registration hosted on GitHub Pages. Registration is stored in a private Supabase database through the registration RPC and does not require the organizer computer to be online.

AI preparation and on-site rewriting remain on the organizer computer. Public arrival/staff pages explain this boundary; no local API is called by the static site.

The publishable Supabase key is intended for the browser; no service-role key, login credentials, participant archives or runtime logs are included.
